# GoInstant

GoInstant was a Canadian (Halifax, Nova Scotia) real-time collaboration startup, founded in 2011, that provided a JavaScript API and backend-as-a-service for building multi-user, real-time web applications — shared/co-browsing, live data synchronization, and presence. Developers embedded a hosted client library to add real-time collaboration to a web page without plugins.

Salesforce acquired GoInstant on 2012-07-09 (reported at ~$70M) and folded the technology into its platform. The standalone GoInstant developer service and website were subsequently discontinued (gone by late 2014).

**Status: defunct / acquired.** This profile is retained as a historical record. GoInstant has no live API, documentation, or developer portal — the `goinstant.com` domain is parked on Salesforce infrastructure and returns no developer surface. No enrichment artifacts could be produced without fabrication.
